## What this source is about

This is a **pure theory and methodology paper**. It argues that scholars should stop treating social media platforms (like "Facebook" or "TikTok") as monolithic variables. Instead, it proposes breaking platforms down into **User Interface Classes (UICs)**—specific "spaces" like Home Pages, Chats, and Algorithmic Feeds that look and act similarly across different apps.

## Method or approach

Mixed-methods computational text analysis:
1. **Latent Dirichlet Allocation (LDA):** Used to identify themes in user descriptions of social media (k=3).
2. **Schematic Semantic Network Analysis (SSNA):** A novel approach using the Louvain community detection algorithm to map how users mentally cluster different digital spaces.
3. **Preprocessing:** Utilized `spaCy` for lemmatization and Part-of-Speech (POS) tagging to distinguish between words used as nouns vs. verbs (e.g., "post").

## Useful claims

- Platforms are "pluralistic and dynamic constructs" and cannot be the sole basis for studying digital effects; we must study **User Interface Classes (UICs)**.
- **Overtly Algorithmic Content Pages (OACPs):** A new, dominant interface class (TikTok FYP, Reels, Shorts) that exposes users primarily to out-of-network content via curated algorithms.
- **Interface Convergence:** Platforms compete by copying each other's successful designs (e.g., everyone copying TikTok’s vertical video feed), making "platformization" a process of cross-platform design standardisation.
- Users cognitively associate different interfaces with different "behavioral states" (e.g., Chats = private/reciprocal; OACPs = passive/discovery).
